# Интерфейс консультанта EKT

Промежуточный результат: адаптивный интерфейс и редактор запроса. API ещё не подключён, запросы в каталог и изменения корзины не выполняются. Это прямо указано в интерфейсе. Реализация интеграции следует согласованному с A контракту.

Требования: Node.js 22.12+ либо поддерживаемая более новая версия, npm.

```sh
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. `npm run build` проверяет TypeScript и собирает статические файлы в `frontend/dist`. Vite проксирует `/api` на `http://127.0.0.1:8000`; финальный единый запуск документирует A в корневом README.

Проверка текущего этапа: нажатие сценария заполняет поле; Enter показывает честное сообщение об отсутствии подключения и сохраняет запрос; Shift+Enter добавляет строку. На телефоне корзина открывается кнопкой в заголовке. В продукте нет вымышленных цен или остатков.

Библиотеки: React (MIT), Vite (MIT), TypeScript (Apache-2.0), Lucide (ISC); IBM Plex Sans и Manrope (SIL OFL, пакеты Fontsource). Точные версии — `package-lock.json`. Эти зависимости существовали до хакатона; код интерфейса создаётся в ходе хакатона при помощи Codex B. Значки Lucide и шрифты поставляются локально, запросов к Google Fonts нет.
