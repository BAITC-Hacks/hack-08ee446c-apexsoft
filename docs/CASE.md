# Кейс №1: ИИ-ассистент-консультант для ekt.kz

Источник: полный информационный пакет, переданный пользователем 23.09.2026; партнёр ТОО «Электрокомплект». Выбран именно этот кейс. Прежняя финансовая разработка остаётся на паузе.

Клиент магазина (частное лицо или закупщик) открывает единый чат, задаёт свободный вопрос про товар/наличие/аналог/условия, при готовности явно подтверждает добавление с количеством и переходит по ссылке на актуальную корзину.

## Обязательная приёмка

1. По существующему артикулу: достоверные наличие, технические характеристики, сертификат ссылкой/файлом, если он есть в каталоге.
2. При нулевом остатке: минимум один релевантный доступный аналог и объяснение; не обещать электротехническую совместимость при нехватке данных.
3. Содержательные ответы об оплате, доставке и минимальной партии на основе официальных источников.
4. Без явного подтверждения корзина неизменна. После подтверждения количество не превышает остаток; проверяются кратность, свежесть цены и остатка.
5. После добавления прямая ссылка ведёт на актуальную корзину текущего клиента.

Вход: текст, фото JPEG, Excel, Word, PDF, сессионный контекст и каталог/остатки. Выход: ответ в чате, карточки/источники, предложение подтверждения, обновлённая корзина/ссылка. Целевая задержка — единицы секунд. Desktop и mobile обязательны.

Каталог: GET https://ekt.kz/api/products (page=N), GET https://ekt.kz/api/products/detail?id=515291. BasicAuth задаётся переменными окружения сервера, секретов в репозитории нет. Поля: артикул, название, категория, характеристики, сертификаты, цена, складские остатки. Прототип может использовать репрезентативную выборку с честной маркировкой источника и времени.

Пользователь подтвердил: это весь доступ, API корзины не предоставлен. Поэтому реализуем собственную сессионную ДЕМОНСТРАЦИОННУЮ корзину и открыто обозначаем границу. Подключение OpenAI разрешено, ключ предоставлен отдельно и в Git/Team MCP не включается.

Нельзя менять корзину/оформлять заказ без подтверждения, выдумывать цены/наличие, запрашивать или хранить платёжные данные. Учитываются приватность, защита корзины, объяснимость аналогов, совместимость встраиваемого интерфейса. Реальная установка на ekt.kz и оформление заказа не подразумеваются доступом к каталогу.

Опционально: казахский язык, сопутствующие товары, постоянная история авторизованных клиентов, эскалация менеджеру. Сначала основной проверенный сценарий.

Артефакты: официальный репозиторий https://github.com/BAITC-Hacks/hack-08ee446c-apexsoft, README с архитектурой, установкой, запуском, данными и приёмкой. Разработка и история с самого начала ведутся в его рабочих ветках.
