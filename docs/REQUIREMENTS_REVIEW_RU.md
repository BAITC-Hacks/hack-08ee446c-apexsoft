## Принципиальные ограничения

Реальная корзина требует API партнёра, тестовой покупательской сессии и разрешённого способа записи. Сейчас доступны только GET каталога. Ссылку /cart нельзя выдавать за checkout магазина.

Сопутствующие рекомендации, авторизованная долговременная история и автоматическая передача диалога оператору не реализованы (опции исходного задания). Ссылка на контакты есть. Спецификации обрабатываются с выбором одной позиции; автоматического пакетного заказа нет.

GitHub Actions ранее блокировался billing lock организации до выполнения шагов. Локальные тесты/сборка не выдаются за зелёный CI. Актуальный SHA и итоговый результат проверки фиксируются в PR. Отправка решения на платформе выполняется участником команды отдельно от merge.
